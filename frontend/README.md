# Jarvis Frontend (Mainline)

Next.js 15 app built from [Mainline template](https://github.com/shadcnblocks/mainline-nextjs-template). Jarvis routes (companies, memo, simulations) will replace or sit alongside the marketing pages.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000. The top-right shows **Backend: ok** when the Jarvis API (port 8000) is running.

Set `NEXT_PUBLIC_API_URL` to point at the backend if not using default `http://localhost:8000`.
